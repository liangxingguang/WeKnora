# WeKnora 部署与配置

## 环境要求

### 基础环境

| 依赖 | 版本要求 |
|------|----------|
| Docker | 20.10+ |
| Docker Compose | 2.0+ |
| Git | 任意版本 |

### 资源要求

| 资源 | 最低配置 | 推荐配置 |
|------|----------|----------|
| CPU | 4 核 | 8 核 |
| 内存 | 8 GB | 16 GB |
| 存储 | 50 GB | 200 GB+ |

## 快速部署

### 1. 克隆仓库

```bash
git clone https://github.com/Tencent/WeKnora.git
cd WeKnora
```

### 2. 配置环境变量

```bash
cp .env.example .env
```

**关键配置项**:

| 配置项 | 说明 | 默认值 |
|--------|------|--------|
| `DB_USER` | 数据库用户名 | (必填) |
| `DB_PASSWORD` | 数据库密码 | (必填) |
| `DB_NAME` | 数据库名称 | (必填) |
| `REDIS_PASSWORD` | Redis 密码 | (必填) |
| `JWT_SECRET` | JWT 密钥 | (必填) |

### 3. 启动服务

```bash
# 启动核心服务
docker compose up -d

# 启动所有服务（包含可选组件）
docker compose --profile full up -d
```

### 4. 访问服务

| 服务 | URL |
|------|-----|
| Web UI | http://localhost |
| 后端 API | http://localhost:8080 |
| 健康检查 | http://localhost:8080/health |

## Docker Compose Profiles

### 可选 Profiles

| Profile | 说明 | 命令 |
|---------|------|------|
| 默认 | 核心服务 | `docker compose up -d` |
| `full` | 全部功能 | `docker compose --profile full up -d` |
| `neo4j` | 知识图谱 | `docker compose --profile neo4j up -d` |
| `minio` | 对象存储 | `docker compose --profile minio up -d` |
| `langfuse` | 链路追踪 | `docker compose --profile langfuse up -d` |
| `qdrant` | Qdrant 向量库 | `docker compose --profile qdrant up -d` |
| `milvus` | Milvus 向量库 | `docker compose --profile milvus up -d` |
| `weaviate` | Weaviate 向量库 | `docker compose --profile weaviate up -d` |
| `doris` | Apache Doris | `docker compose --profile doris up -d` |
| `searxng` | SearXNG 搜索 | `docker compose --profile searxng up -d` |
| `dex` | OIDC 认证 | `docker compose --profile dex up -d` |

### 组合使用

```bash
# 同时启动多个 Profiles
docker compose --profile neo4j --profile minio --profile langfuse up -d
```

## 环境变量详解

### 数据库配置

```bash
DB_DRIVER=postgres           # 数据库驱动
DB_HOST=postgres             # 数据库主机
DB_PORT=5432                 # 数据库端口
DB_USER=weknora              # 用户名
DB_PASSWORD=password         # 密码
DB_NAME=weknora              # 数据库名
```

### Redis 配置

```bash
REDIS_ADDR=redis:6379        # Redis 地址
REDIS_PASSWORD=password      # Redis 密码
REDIS_DB=0                   # 数据库编号
REDIS_PREFIX=weknora:        # Key 前缀
```

### 安全配置

```bash
JWT_SECRET=your-secret-key   # JWT 密钥（必填）
CRYPTO_MASTER_KEY=xxx        # 加密主密钥
CRYPTO_SALT=xxx              # 加密盐值
DISABLE_REGISTRATION=false   # 是否禁用注册
```

### 向量存储配置

#### PostgreSQL (pgvector)

默认使用 ParadeDB 镜像，内置 pgvector 支持。

#### Qdrant

```bash
QDRANT_HOST=qdrant           # Qdrant 主机
QDRANT_PORT=6334             # Qdrant 端口
QDRANT_COLLECTION=weknora_embeddings
QDRANT_API_KEY=              # API Key（可选）
```

#### Milvus

```bash
MILVUS_ADDRESS=milvus:19530  # Milvus 地址
MILVUS_COLLECTION=weknora_embeddings
MILVUS_METRIC_TYPE=IP        # 度量类型
```

#### Elasticsearch

```bash
RETRIEVE_DRIVER=elasticsearch
ELASTICSEARCH_ADDR=http://elasticsearch:9200
ELASTICSEARCH_USERNAME=elastic
ELASTICSEARCH_PASSWORD=changeme
```

### 对象存储配置

#### 本地存储

```bash
STORAGE_TYPE=local
LOCAL_STORAGE_BASE_DIR=/data/files
```

#### MinIO

```bash
STORAGE_TYPE=minio
MINIO_ENDPOINT=minio:9000
MINIO_ACCESS_KEY_ID=minioadmin
MINIO_SECRET_ACCESS_KEY=minioadmin
MINIO_BUCKET_NAME=weknora
```

#### AWS S3

```bash
STORAGE_TYPE=s3
MINIO_ENDPOINT=s3.amazonaws.com
MINIO_ACCESS_KEY_ID=your-key
MINIO_SECRET_ACCESS_KEY=your-secret
MINIO_BUCKET_NAME=weknora
```

#### 腾讯云 COS

```bash
STORAGE_TYPE=cos
COS_SECRET_ID=your-secret-id
COS_SECRET_KEY=your-secret-key
COS_REGION=ap-guangzhou
COS_BUCKET_NAME=your-bucket
COS_APP_ID=your-app-id
```

### LLM 配置

#### Ollama

```bash
OLLAMA_BASE_URL=http://host.docker.internal:11434
```

> 需在宿主机运行 `ollama serve`

#### OpenAI

通过模型管理界面配置，不在环境变量中设置。

### Langfuse 配置

```bash
LANGFUSE_ENABLED=true
LANGFUSE_HOST=http://langfuse-web:3000
LANGFUSE_PUBLIC_KEY=your-key
LANGFUSE_SECRET_KEY=your-secret
```

### 文档解析服务配置

```bash
DOCREADER_ADDR=docreader:50051
DOCREADER_TRANSPORT=grpc

# gRPC TLS 配置（可选）
GRPC_TLS_ENABLED=false
GRPC_AUTH_TOKEN=your-token
```

### 租户与权限配置

```bash
WEKNORA_TENANT_ENABLE_RBAC=true        # 是否启用 RBAC
WEKNORA_TENANT_MAX_OWNED_PER_USER=3    # 单用户最大租户数
```

### 安全配置

```bash
SSRF_WHITELIST=                        # SSRF 白名单
SSRF_WHITELIST_EXTRA=searxng,qdrant,milvus
IMAGE_HOST_KEEP_URL=                   # 保留原始图片 URL 的域名白名单
```

### 性能配置

```bash
CONCURRENCY_POOL_SIZE=5                # 并发池大小
WEKNORA_ASYNQ_CONCURRENCY=32           # 任务队列并发数
WEKNORA_AGENT_LLM_TIMEOUT=120         # Agent LLM 调用超时（秒）
```

## 配置文件

### 主配置文件

**路径**: [config/config.yaml](file:///d:/workplace/Weknora/config/config.yaml)

```yaml
server:
  port: 8080
  host: "0.0.0.0"

conversation:
  max_rounds: 5
  keyword_threshold: 0.3
  embedding_top_k: 30
  vector_threshold: 0.2
  rerank_threshold: 0.3
  rerank_top_k: 30
  fallback_strategy: "model"
  enable_rewrite: true
  enable_query_expansion: true
  enable_rerank: true

knowledge_base:
  chunk_size: 512
  chunk_overlap: 80
  split_markers: ["\n\n", "\n", "。"]
  document_process_timeout: 2h
  image_processing:
    enable_multimodal: true

tenant:
  enable_cross_tenant_access: false
```

### Agent 类型预设

**路径**: [config/agent_type_presets.yaml](file:///d:/workplace/Weknora/config/agent_type_presets.yaml)

定义内置 Agent 类型的配置模板。

### 内置模型配置（可选）

**路径**: `config/builtin_models.yaml`

```yaml
models:
  - id: openai-gpt-4o
    name: OpenAI GPT-4o
    type: chat
    provider: openai
    display_name: "GPT-4o"
    config:
      api_base: ${OPENAI_API_BASE}
      model: gpt-4o
```


## 安全建议

### 生产环境配置

1. **修改默认密码**: 所有服务的默认密码必须修改
2. **启用 TLS**: 在前端配置 HTTPS
3. **限制网络访问**: 不要直接暴露服务到公网
4. **配置防火墙**: 仅允许必要的端口访问
5. **定期更新**: 及时更新镜像版本

### 敏感信息管理

- API Key 和凭据使用 AES-256-GCM 加密存储
- 定期轮换加密密钥
- 不在日志中打印敏感信息

## 常见问题

### 1. 服务启动失败

**检查日志**:
```bash
docker compose logs app
docker compose logs postgres
docker compose logs redis
```

**检查端口占用**:
```bash
netstat -tlnp | grep 8080
```

### 2. 文档上传失败

**检查存储配置**:
```bash
# 检查本地存储目录权限
ls -la /data/files

# 检查 MinIO 连接
docker compose exec minio mc admin info local
```

### 3. LLM 调用失败

**检查网络连接**:
```bash
docker compose exec app curl -I https://api.openai.com/v1
```

**检查模型配置**:
```bash
# 在 Web UI 中测试模型连接
# 路径: Settings → Models → Test Connection
```

### 4. 向量检索异常

**检查向量存储连接**:
```bash
docker compose exec app curl http://qdrant:6333/collections
```

**检查嵌入模型**:
```bash
# 在 Web UI 中测试嵌入模型
# 路径: Settings → Models → Test Connection
```

### 5. 内存不足

**增加内存限制**:
```yaml
# docker-compose.yml
app:
  deploy:
    resources:
      limits:
        memory: 8G
      reservations:
        memory: 4G
```

## 监控与运维

### Langfuse 可观测性

1. 启动 Langfuse: `docker compose --profile langfuse up -d`
2. 访问 UI: http://localhost:3000
3. 配置 API Key: Settings → API Keys
4. 在 `.env` 中配置:
   ```bash
   LANGFUSE_ENABLED=true
   LANGFUSE_HOST=http://langfuse-web:3000
   LANGFUSE_PUBLIC_KEY=your-key
   LANGFUSE_SECRET_KEY=your-secret
   ```

### 健康检查

```bash
# 应用健康检查
curl http://localhost:8080/health

# 数据库健康检查
docker compose exec postgres pg_isready -U weknora

# Redis 健康检查
docker compose exec redis redis-cli -a password ping
```

### 性能监控

```bash
# Docker 资源使用
docker stats

docker compose top app

# 内存分析
```
