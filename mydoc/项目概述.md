# WeKnora 项目概述

## 项目简介

**WeKnora（维娜拉）** 是一款开源的、基于大语言模型（LLM）的知识管理框架，专为企业级文档理解、语义检索与智能推理场景打造。由腾讯微信对话开放平台团队开发维护。

### 官方信息

- **官方网站**: https://weknora.weixin.qq.com
- **GitHub 仓库**: https://github.com/Tencent/WeKnora
- **许可协议**: MIT License
- **当前版本**: v0.6.3

## 核心能力

框架围绕三大核心能力构建：

| 能力 | 描述 |
|------|------|
| **RAG 快速问答** | 基于知识库的语义检索问答，快速准确地回答问题 |
| **ReAct Agent 智能推理** | 自主编排知识检索、MCP 工具与网络搜索完成复杂多步任务 |
| **Wiki 模式** | Agent 从原始文档中自治生成相互链接的 Markdown 知识库与可视化知识图谱 |

## 功能特性

### 智能对话

- ReACT 渐进式多步推理
- 在线 Prompt 编辑、检索阈值调节
- 多轮上下文感知
- 推荐问题自动生成
- 对话内引用浮层与 RAG 流水线分阶段进度展示
- 会话按来源（Web / IM / 嵌入）筛选与分组

### 知识管理

- 多类型知识库：FAQ / 文档 / Wiki
- 支持文件夹导入、URL 导入、多标签管理
- 按批次解析配置（process_config）
- 批量重新解析
- 数据源自动同步（飞书 / Notion / 语雀 / RSS）
- 支持 10+ 文档格式：PDF / Word / Txt / Markdown / HTML / EPUB / MHTML / 图片 / CSV / Excel / PPT / JSON
- 多种检索策略：BM25 / Dense / GraphRAG / 父子分块 / HNSW 加速

### 集成扩展

- **模型厂商**: OpenAI / Azure OpenAI / Anthropic / DeepSeek / Qwen / 智谱 / 混元 / Gemini / MiniMax / NVIDIA / Ollama 等 20+
- **向量数据库**: PostgreSQL (pgvector) / Elasticsearch / OpenSearch / Milvus / Weaviate / Qdrant / Apache Doris / 腾讯云 VectorDB
- **对象存储**: 本地 / MinIO / AWS S3 / 火山引擎 TOS / 阿里云 OSS / 金山云 KS3 / 华为云 OBS
- **IM 集成**: 企业微信 / 飞书 / Slack / Telegram / 钉钉 / Mattermost / 微信
- **网络搜索**: DuckDuckGo / Bing / Google / Tavily / Baidu / SearXNG

### 平台能力

- 部署方式：本地 / Docker / Kubernetes (Helm)
- 界面：Web UI / RESTful API / CLI / Chrome Extension / 网站嵌入 Widget / 微信小程序
- 权限控制：租户 RBAC 四级角色矩阵（Owner / Admin / Contributor / Viewer）
- 安全：AES-256-GCM 加密、gRPC TLS、防 SSRF、技能沙箱隔离
- 可观测性：Langfuse 全链路追踪

## 项目结构

```
WeKnora/
├── cli/                    # 命令行工具
├── client/                 # Go 客户端 SDK
├── cmd/                    # 命令入口（server/desktop/download）
├── config/                 # 配置文件模板
├── docreader/              # 文档解析服务（Python）
├── docs/                   # 官方文档
├── frontend/               # 前端应用（Vue3 + TypeScript）
├── helm/                   # Kubernetes Helm Chart
├── internal/               # 后端核心代码
│   ├── agent/              # Agent 引擎
│   ├── application/        # 应用层（service/repository）
│   ├── handler/            # HTTP 处理层
│   ├── im/                 # IM 适配器
│   ├── models/             # LLM 模型接口
│   ├── mcp/                # MCP 服务管理
│   ├── middleware/         # 中间件
│   ├── types/              # 类型定义
│   └── infrastructure/     # 基础设施层
├── mcp-server/             # Python MCP 服务
├── miniprogram/            # 微信小程序
├── migrations/             # 数据库迁移脚本
└── scripts/                # 部署脚本
```

## 快速开始

```bash
git clone https://github.com/Tencent/WeKnora.git
cd WeKnora
cp .env.example .env
docker compose up -d
```

访问 http://localhost 即可使用。
